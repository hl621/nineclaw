检索测试 API（RAGFlow 兼容）

参照 RAGFlow Retrieve chunks 实现。

当前为本地文件系统演示检索（关键词 + 相似度打分），尚未接入向量数据库；响应结构与 RAGFlow 保持一致，便于后续替换为真实 RAG 引擎。

端点​

方法路径说明
POST/v1/retrieval与 RAGFlow POST /api/v1/retrieval 路径对应
POST/v1/knowledge/retrieval同上，挂在 knowledge 模块下
POST/v1/knowledge/{kb_id}/retrieval单知识库检索，dataset_ids 固定为 {kb_id}
POST/v1/knowledge/{kb_id}/recall旧版兼容接口，内部走检索逻辑

请求体​

{
  "question": "如何重置密码？",
  "dataset_ids": ["your-kb-id"],
  "document_ids": [],
  "page": 1,
  "page_size": 30,
  "similarity_threshold": 0.2,
  "vector_similarity_weight": 0.3,
  "top_k": 1024,
  "keyword": false,
  "highlight": true
}
字段类型必填说明
questionstring是查询问题
dataset_idsstring[]与 document_ids 二选一知识库 ID（对应 RAGFlow dataset）
document_idsstring[]否限定文档（知识库内文件 id）
pageint否页码，默认 1
page_sizeint否每页条数，默认 30
similarity_thresholdfloat否最低相似度，默认 0.2
vector_similarity_weightfloat否向量权重，默认 0.3
top_kint否参与排序的 chunk 上限，默认 1024
keywordbool否是否启用关键词严格匹配
highlightbool否是否在 highlight 字段用 <em> 包裹命中词
metadata_conditionobject否元数据过滤（本地暂未索引，预留）

示例​

多库检索​

curl -X POST "http://127.0.0.1:8000/v1/retrieval" \
  -H "Content-Type: application/json" \
  -H "X-Tenant-ID: default" \
  -d '{
    "question": "如何重置密码？",
    "dataset_ids": ["kb-demo"],
    "similarity_threshold": 0.2,
    "vector_similarity_weight": 0.3,
    "highlight": true
  }'

单库检索​

curl -X POST "http://127.0.0.1:8000/v1/knowledge/kb-demo/retrieval" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "如何重置密码？",
    "dataset_ids": [],
    "page": 1,
    "page_size": 10,
    "highlight": true
  }'

旧版 recall 兼容​

curl -X POST "http://127.0.0.1:8000/v1/knowledge/kb-demo/recall" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "如何重置密码？",
    "similarity": 0.2,
    "vector_weight": 0.3
  }'
