文档切片启用 / 停用

对接 RAGFlow 切片字段 available（true = 参与检索，false = 停用）。

需配置 KNOWLEDGE_BACKEND=ragflow 且填写 RAGFLOW_*。

接口一览​

方法路径说明
GET/v1/knowledge/{kb_id}/files/{file_id}/chunks切片列表（含 available）
PATCH/v1/knowledge/{kb_id}/files/{file_id}/chunks/{chunk_id}单个切片启用/停用
PATCH/v1/knowledge/{kb_id}/files/{file_id}/chunks批量启用/停用
GET/v1/datasets/{dataset_id}/documents/{document_id}/chunks同上（RAGFlow 路径）
PATCH/v1/datasets/{dataset_id}/documents/{document_id}/chunks/{chunk_id}同上
PATCH/v1/datasets/{dataset_id}/documents/{document_id}/chunks同上（批量）

kb_id / dataset_id 为知识库 ID；file_id / document_id 为文档 ID。

列出切片​

GET /v1/knowledge/{kb_id}/files/{file_id}/chunks?page=1&page_size=100

响应 data 示例：

{
  "chunks": [
    {
      "id": "b48c170e90f70af998485c1065490726",
      "content": "切片正文…",
      "available": true,
      "important_keywords": []
    }
  ],
  "total": 12
}

单个切片启用 / 停用​

PATCH /v1/knowledge/{kb_id}/files/{file_id}/chunks/{chunk_id}
Content-Type: application/json

{"available": false}

响应：

{
  "code": 0,
  "data": {
    "chunk_id": "b48c170e90f70af998485c1065490726",
    "available": false
  }
}

批量切换​

PATCH /v1/knowledge/{kb_id}/files/{file_id}/chunks
Content-Type: application/json

{
  "chunk_ids": ["id1", "id2"],
  "available": true
}

实现说明​

  • 业务逻辑：app/services/knowledge_chunk_service.py
  • RAGFlow 代理：PATCH /api/v1/datasets/.../chunks/{chunk_id}、PATCH .../chunks（批量）
  • 本地 filesystem 模式仅支持列表预览分块，不支持写入启用状态（返回 501）

检索与问答​

知识问答、召回测试均通过 retrieve_chunks 拉取切片；available=false 的切片会被自动排除，不会进入引用列表或 LLM 上下文。
