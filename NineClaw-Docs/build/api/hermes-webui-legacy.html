Hermes WebUI Legacy API

旧的手写版本，保留为历史参考，不再作为侧边栏入口使用。

每个 nineclaw 实例内置一个 Hermes WebUI 服务（容器端口 8643），通过 Traefik 统一入口对外暴露。

访问地址格式​

http://<host>:8510/traefik/nineclaw/<instance_id>/webui/<path>

例如，实例 ID 为 84d07aeed0844abf 时：

http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/

Traefik 会将该请求转发到对应容器的 http://127.0.0.1:8787/（即容器内 8643 端口），并自动剥离路径前缀。

注意：本文档中所有端点路径（如 GET /api/chat/start）均为相对路径，实际请求时需拼接完整前缀，例如：

http://<host>:8510/traefik/nineclaw/<instance_id>/webui/api/chat/start

会话管理​

GET /api/sessions​

Request​

  • Method: GET
  • URL: http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/sessions
  • Auth: 无需 Token
Request example​
curl "http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/sessions?limit=20&offset=0"
Request Parameters​
参数位置类型必填说明
limitQueryinteger否返回会话数，默认 20
offsetQueryinteger否分页偏移，默认 0

Response​

Success:

{
  "sessions": [
    {
      "id": "a1b2c3d4e5f6",
      "source": "webui",
      "model": "anthropic/claude-sonnet-4.6",
      "title": "项目讨论",
      "started_at": 1748000000,
      "ended_at": null,
      "last_active": 1748001000,
      "is_active": true,
      "message_count": 15,
      "tool_call_count": 3,
      "input_tokens": 5000,
      "output_tokens": 2000,
      "preview": "帮我分析这个代码..."
    }
  ],
  "total": 42,
  "limit": 20,
  "offset": 0
}

Failure:

{"error": "无法获取会话列表"}

POST /api/session/new​

Request​

  • Method: POST
  • URL: http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/session/new
  • Auth: 无需 Token
  • Headers: Content-Type: application/json
Request example​
curl -X POST http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/session/new \
  -H "Content-Type: application/json" \
  -d '{"workspace": "/home/user/project", "model": "anthropic/claude-sonnet-4.6"}'
Request Parameters​
参数位置类型必填说明
workspaceBodystring否工作区路径
modelBodystring否模型名称

Response​

Success:

{
  "session_id": "a1b2c3d4e5f6",
  "title": "新会话",
  "workspace": "/home/user/project",
  "created_at": 1748000000.0
}

Failure:

{"error": "创建失败"}

对话与 Agent 交互​

POST /api/chat/start​

Request​

  • Method: POST
  • URL: http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/chat/start
  • Auth: 无需 Token
  • Headers: Content-Type: application/json
Request example​
curl -X POST http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/chat/start \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "a1b2c3d4e5f6",
    "message": "帮我列出当前目录的文件",
    "model": "anthropic/claude-sonnet-4.6"
  }'
Request Parameters​
参数位置类型必填说明
session_idBodystring是会话 ID
messageBodystring是用户消息
modelBodystring否模型名称，不指定则使用会话默认模型

Response​

Success:

{"stream_id": "f7e8d9c0b1a2"}

Failure:

{"error": "会话不存在"}

GET /api/chat/stream​

Request​

  • Method: GET
  • URL: http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/chat/stream
  • Auth: 无需 Token
Request example​
curl -N "http://127.0.0.1:8510/traefik/nineclaw/84d07aeed0844abf/webui/api/chat/stream?stream_id=f7e8d9c0b1a2"
Request Parameters​
参数位置类型必填说明
stream_idQuerystring是由 /api/chat/start 返回的流 ID

Response​

Success（SSE 事件流）:

事件数据说明
token{"text": "..."}LLM 文本增量
tool{"name": "terminal", "preview": "ls"}工具调用开始
approval{"command": "...", "description": "..."}需要审批
done{"session": {...}}完成，含完整会话
error{"message": "...", "trace": "..."}出错

Failure:

{"error": "stream_id 不存在"}

错误响应​

所有错误响应遵循以下格式：

{"error": "错误描述信息"}
HTTP 状态码说明
400请求参数无效
401未认证
403路径遍历被拒绝 / 跨域请求被拒绝
404资源不存在
409状态冲突
413上传文件超过大小限制
500服务器内部错误
