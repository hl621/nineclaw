knowledge

基于文件系统的知识库（RAG）注册表，NineClaw Manager 自研接口。

服务基址​

http://172.18.33.28:8000
接口方法路径
健康检查GET/health
知识库列表GET/v1/knowledge
创建知识库POST/v1/knowledge
知识库详情GET/v1/knowledge/{id}
更新PUT/v1/knowledge/{id}
删除DELETE/v1/knowledge/{id}
上传文档POST/v1/knowledge/{id}/files
文件列表GET/v1/knowledge/{id}/files（含 progress / progress_msg，WebUI 轮询进度条）
切片图片代理GET/v1/knowledge/images/{image_id}（RAGFlow 切片配图，供 WebUI 预览）
下载文档GET/v1/knowledge/{id}/files/{file_id}/download
媒体内容GET/v1/knowledge/{id}/files/{file_id}/media-content（RAGFlow 后端；可选）
媒体转写POST/v1/knowledge/{id}/files/{file_id}/media-transcribe（RAGFlow 默认 ASR；可选）
刷新索引POST/v1/knowledge/{id}/reindex
解析文档POST/v1/datasets/{id}/chunks 或 /v1/knowledge/{id}/chunks

解析文档接口详见 parse-documents.md。RAGFlow 映射与库级状态汇总见 ragflow-integration.md。

Apifox：导入 knowledge-create.openapi.yaml。

  • KNOWLEDGE_BACKEND=filesystem：数据目录 KNOWLEDGE_STORAGE_PATH（默认 ./knowledge_storage）。
  • KNOWLEDGE_BACKEND=ragflow：转发到外部 RAGFlow。WebUI 详情预览对音视频只下载并播放文件，不调用 media-transcribe；切片与问答依赖 RAGFlow 解析结果。详情页文件行悬停进度条来自文件列表中的 progress。

知识库 status（库级）​

值含义
pending待构建
building构建中
success已就绪（全部文档解析成功）
part_success部分异常（界面文案；有成功也有失败）
fail构建失败（全部失败）

数据模型​

class KnowledgeFileResponse(BaseModel):
    id: str
    name: str
    size_bytes: int
    parsed: bool
    parse_failed: bool
    chunk_count: int
    progress: float | None          # RAGFlow 解析进度（0–1 或 0–100）
    progress_msg: str | None        # 进度详情 / 失败原因
    preview: str | None
    uploaded_at: datetime | None

class KnowledgeResponse(BaseModel):
    id: str
    name: str
    description: str
    group: str
    owner: str
    serial: str | None
    status: Literal["pending", "building", "success", "part_success", "fail"]
    doc_count: int
    updated_at: datetime
    avatar: str | None
    embedding_model: str | None
    chunk_method: str | None
    permission: str | None
    parser_config: dict | None

class KnowledgeDetailResponse(KnowledgeResponse):
    files: list[KnowledgeFileResponse]

存储布局​

$KNOWLEDGE_STORAGE_PATH/
├── support-faq/
│   ├── meta.json
│   └── documents/
│       └── abc123_概述.md

路由​

POST /v1/knowledge​

创建知识库（参数全部写入本地 meta.json）：

{
  "name": "客服 FAQ",
  "description": "高频问答",
  "group": "业务运营",
  "owner": "小隆",
  "embedding_model": "bge-large@local",
  "permission": "me",
  "chunk_method": "naive",
  "parser_config": {
    "chunk_token_num": 128,
    "delimiter": "\\n",
    "layout_recognize": "DeepDOC",
    "html4excel": false,
    "raptor": { "use_raptor": false },
    "graphrag": { "use_graphrag": false }
  }
}

id 省略时从 name slugify；冲突返回 409。

DELETE /v1/knowledge/{id}​

删除指定知识库（删除磁盘上整个目录，含 meta.json 与 documents/）。

路径参数

参数说明
id知识库 ID（创建时返回的 data.id，或列表项 id）

请求示例

curl -X DELETE "http://172.18.33.28:8000/v1/knowledge/apifox-test-kb" \
  -H "X-Tenant-ID: default"

成功响应 200

{
  "code": 0,
  "message": "success",
  "data": {
    "deleted": "apifox-test-kb"
  }
}

错误

HTTP说明
404知识库不存在
500删除目录失败

GET /v1/knowledge/{id}/files/{file_id}/download​

下载知识库中的单个文档（返回原始文件流，非 JSON 信封）。

路径参数

参数说明
id知识库 ID
file_id文件 ID（详情接口 files[].id，即磁盘上的存储文件名）

请求示例

curl -O -J "http://172.18.33.28:8000/v1/knowledge/my-kb/files/abc123_概述.md/download" \
  -H "X-Tenant-ID: default"

成功响应 200：Content-Disposition: attachment; filename="概述.md"，响应体为文件二进制内容。

错误：404 知识库或文件不存在；400 无效 file_id。

POST /v1/knowledge/qa（SSE 流式）​

知识问答，请求体：

{
  "question": "如何重置密码？",
  "dataset_ids": ["support-faq", "trade-war"],
  "top_k": 5,
  "cross_languages": ["Chinese", "English"]
}

dataset_ids 即知识库 ID（/v1/knowledge 列表中的 id）。
cross_languages（可选）透传 RAGFlow 跨语言检索；WebUI 问答 / 召回设置中的「目标语言」即写入该字段。用户操作见手册 RAG — 跨语言检索。

SSE 响应（text/event-stream）：

data: {"type": "references", "references": [{"dataset_id":"...", "file_name":"...", "text":"...", "score":0.8}]}

data: {"type": "content", "content": "回答片段"}

data: [DONE]

单库快捷：POST /v1/knowledge/{id}/qa，body {"question":"...", "top_k": 5}，效果相同。

GET /v1/knowledge/qa/model 返回服务端 .env 配置的默认问答模型（前端展示用，无需在「模型管理」选择）。

其余路由：文件上传/删除、reindex、recall — 见 Manager /docs。

配置​

环境变量默认说明
KNOWLEDGE_STORAGE_PATH./knowledge_storage知识库根目录
KNOWLEDGE_MAX_UPLOAD_SIZE52428800单文件上传上限（字节）
KNOWLEDGE_QA_LLM_BASE_URL—知识问答大模型 API 基址（OpenAI 兼容）
KNOWLEDGE_QA_LLM_API_KEY—知识问答 API Key
KNOWLEDGE_QA_LLM_MODEL—模型名，如 MiniMax-M2.7
