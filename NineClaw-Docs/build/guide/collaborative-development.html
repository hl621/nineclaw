协同开发

本页只回答一个问题：你现在要开发哪一层，本地应该启动什么服务，应该改哪些 .env。

这张图是远端 Deploy 环境的基准形态：NineClaw-Deploy 在服务器上通过 docker-compose.yml 组织 Traefik、WebUI、Manager、WebSearch、Runtime、PostgreSQL 等组件。后面三张图只是在这个远端环境之外，说明本地开发时替换或复用哪些服务。

开发内容看哪一节核心配置
只改前端只开发前端WebUI 指向远端 Manager 和远端 Traefik
前后端一起联调前后端一起开发WebUI 指向本地 Manager，Manager 继续使用远端 PostgreSQL
涉及表结构或测试数据本地数据库开发Manager 改连本地 PostgreSQL

下方图中的示例地址使用 127.0.0.1 表示本地开发机，172.18.33.24 表示远端 Deploy 服务器。换环境时替换成实际服务器 IP 即可。

只开发前端​

适合只改 NineClaw-WebUI 的页面、交互、样式或前端逻辑。此时本地只启动 WebUI，Manager、Traefik、PostgreSQL 和 Runtime 路由都复用远端 Deploy 环境。

修改 NineClaw-WebUI/.env：

PUBLIC_BACKEND_URL=http://172.18.33.24:8080
PUBLIC_TRAEFIK_URL=http://172.18.33.24:8510

这两个变量分别控制：

变量指向
PUBLIC_BACKEND_URL远端 NineClaw-Manager 直连端口
PUBLIC_TRAEFIK_URL远端 Traefik 入口

启动前端：

cd ./NineClaw-WebUI
pnpm install
pnpm dev

浏览器访问 http://127.0.0.1:5173。

前后端一起开发​

适合同时改 NineClaw-WebUI 和 NineClaw-Manager，做接口联调。此时本地启动 WebUI 和 Manager，但数据库仍使用远端 PostgreSQL，所以不要在这种模式下改表结构或破坏共享测试数据。

修改 NineClaw-WebUI/.env：

PUBLIC_BACKEND_URL=http://127.0.0.1:8000
PUBLIC_TRAEFIK_URL=http://172.18.33.24:8510

修改 NineClaw-Manager/.env：

PUBLIC_TRAEFIK_URL=http://172.18.33.24:8510
DATABASE_URL=postgresql+asyncpg://postgres:password@172.18.33.24:15432/nineclaw_manager

配置结果：

配置位置变量指向
NineClaw-WebUI/.envPUBLIC_BACKEND_URL本地 Manager
NineClaw-WebUI/.envPUBLIC_TRAEFIK_URL远端 Traefik
NineClaw-Manager/.envPUBLIC_TRAEFIK_URL远端 Traefik
NineClaw-Manager/.envDATABASE_URL远端 PostgreSQL

这个模式的关键点是：前端请求本地后端，后端继续读写远端共享库。它适合功能联调，不适合数据库变更。

本地数据库开发​

适合后端改动涉及表结构、迁移脚本、破坏性测试或隔离测试数据。此时本地启动 PostgreSQL，让 NineClaw-Manager 改连本地数据库，避免影响其他人使用远端共享库。

修改 NineClaw-WebUI/.env：

PUBLIC_BACKEND_URL=http://127.0.0.1:8000
PUBLIC_TRAEFIK_URL=http://172.18.33.24:8510

修改 NineClaw-Manager/.env：

PUBLIC_TRAEFIK_URL=http://172.18.33.24:8510
DATABASE_URL=postgresql+asyncpg://postgres:password@127.0.0.1:15432/nineclaw_manager

配置结果：

配置位置变量指向
NineClaw-WebUI/.envPUBLIC_BACKEND_URL本地 Manager
NineClaw-WebUI/.envPUBLIC_TRAEFIK_URL远端 Traefik
NineClaw-Manager/.envPUBLIC_TRAEFIK_URL远端 Traefik
NineClaw-Manager/.envDATABASE_URL本地 PostgreSQL

本地 PostgreSQL 可以用 NineClaw-Manager/docker-compose.yml 启动：

cd ./NineClaw-Manager
docker compose up -d postgres

确认本地库可用后，再启动本地 Manager 和 WebUI。这个模式下可以放心验证 Schema 调整、迁移脚本和测试数据。
