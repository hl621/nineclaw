Skill（技能库）

Skill 页面用于管理可复用技能。一个 Skill 是给智能体准备的一组能力说明、脚本和参考资料，帮助它在合适场景下按既定方法完成任务。

Skill 保存或导入后，还需 部署 到 运行中 的 NineClaw 实例，智能体才能在任务中调用。也可在 NineClaw 创建实例 向导的步骤 3 中勾选 Skill，省去单独部署。

访问地址示例：http://xxx:8510/skills

进入页面​

  1. 打开 NineClaw WebUI。
  2. 在左侧导航中点击 Skill。
  3. 页面会展示已有技能卡片。

页面上能看到什么​

区域说明
搜索框按名称、描述或标签查找技能
+ 创建从空白 Skill 开始创建
上传导入已有 Skill 压缩包
部署把选中的 Skill 应用到 NineClaw 实例
Skill 卡片展示技能名称、描述、标签、文件数量和更新时间

点击 Skill 卡片可以进入 Skill Studio，在里面查看文件、编辑说明、使用 AI 辅助修改并做简单测试。

创建 Skill​

适合从零开始创建一个新技能。

  1. 点击 + 创建。
  2. 填写名称和描述。
  3. 点击 创建。
  4. 创建成功后，点击卡片进入 Skill Studio 继续编辑。

名称和描述要尽量清楚，因为智能体会依赖这些信息判断什么时候应该使用这个技能。

上传 Skill 包​

适合导入别人已经准备好的 Skill（单个 skill，或包含多个 skill 的合集 zip）。

  1. 点击 上传，打开 上传 Skill 包 弹窗。
  2. 用下面任一方式提供 .zip：
    • 点击选择：点击虚线区域内的 选择 zip，或直接点击虚线区域，在文件对话框中选中 zip；
    • 拖拽上传：把本地 .zip 拖到虚线区域内，松手后开始解析（拖入时区域会高亮提示）。
  3. 等待系统递归扫描 zip 内所有 SKILL.md，并在弹窗中显示识别结果。
  4. 点击 确定 进入预览，勾选要导入的 Skill。
  5. 如果检测到重名，按需勾选 覆盖。
  6. 点击 开始导入，等待导入完成。

状态说明
已存在平台中已有同名 Skill
覆盖勾选后会替换已有 Skill
跳过未勾选覆盖时，同名 Skill 会被跳过
失败压缩包格式或 Skill 内容不符合要求

说明： 仅支持 .zip。可用 点击选择 或 拖拽到虚线区域；若拖拽无反应，请改用点击选择。解析进行中时请勿再次拖入或选择文件；非 zip 文件会提示错误。通过局域网 http:// 访问 WebUI 时，上传预览应正常完成，不应出现整页灰屏或白屏。

使用 Skill Studio​

点击任意 Skill 卡片进入详情页。

区域功能
左侧文件树查看 Skill 目录下的文件
中间编辑区查看或编辑文件内容
右侧对话面板用 AI 辅助生成、修改或测试 Skill

常见操作：

  1. 打开 SKILL.md 查看技能说明。
  2. 修改内容后点击 保存。
  3. 需要时使用 AI 辅助修改说明或代码（输入框可用 ↑ / ↓ 翻历史）。
  4. 在右侧描述你想补充或调整的能力。
  5. 切换到测试模式，验证 Skill 是否能被正确理解。

部署到 NineClaw 实例​

部署前请确认目标实例处于 运行中。若尚未创建实例，请先到 NineClaw 创建。

  1. 在 Skill 列表页点击 部署。
  2. 选择要部署的 Skill。
  3. 选择一个或多个 运行中 的 NineClaw 实例。
  4. （如有）选择写入实例的技能 分类目录；未分类时界面会显示为 默认（未分类），技能会进入实例原生技能目录，可在实例「技能」面板中看到。
  5. 点击 开始。
  6. 等待部署完成；若失败，页面会展示实例返回的真实错误（不会再误报“成功”）。

部署完成后，可以打开目标实例 WebUI，让智能体执行一个需要该技能的任务，确认是否生效。

注意事项​

场景说明
Skill 描述不清楚智能体可能不知道什么时候调用它
上传包无法识别检查压缩包中是否包含符合规范的 SKILL.md
仅支持 .zip请用点击选择或拖拽上传 zip，不支持其他压缩格式
勾选覆盖会替换已有同名 Skill，操作前要确认
部署失败优先检查目标实例是否运行中；阅读页面错误原文后再重试
默认（未分类）未指定分类时写入实例默认技能目录，属预期行为

常见排查​

现象优先检查
上传后没有识别到 Skill压缩包结构是否正确，是否包含 SKILL.md（支持递归扫描子目录）
拖拽后无反应是否拖入虚线区域；文件是否为 .zip；是否仍在「正在上传并解析」中
上传后整页灰屏 / 白屏刷新页面后重试；确认当前 WebUI 版本已包含上传修复；仍失败时打开浏览器控制台查看报错
Skill 无法保存文件内容是否有格式错误，服务是否正常
部署提示成功但实例没有该技能是否选了正确实例；分类是否为「默认（未分类）」；刷新实例技能面板；升级 Manager 后重新部署
部署失败却像成功升级 WebUI：当前版本会如实展示实例错误
部署后实例无法使用是否部署到正确实例，实例是否完成重新加载
智能体没有调用 SkillSkill 名称、描述和触发场景是否写清楚
