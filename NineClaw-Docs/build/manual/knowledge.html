RAG（知识库）

RAG 页面用于管理知识库。你可以在这里创建知识库、上传文档、查看解析结果、测试召回效果，并把知识库部署到 NineClaw 实例中。

使用前提： 知识库底层依赖 QYRAG / RAGFlow。须先 QYRAG 部署，再 QYRAG 配置 完成对接。日常上传、问答在 NineClaw WebUI 完成。

上传格式一览： 支持的文件格式（RAGFlow / NineClaw） — 用户可直接打开该节查看 WebUI 可上传列表与 RAGFlow 官方文档链接。

配置知识库后，还需点击 部署 并选择 运行中 的实例，智能体才能在对话中检索文档。也可在 NineClaw 创建实例 向导的步骤 4 中勾选 RAG。

访问地址示例：http://xxx:8510/knowledge

进入页面​

  1. 打开 NineClaw WebUI。
  2. 在左侧导航中点击 RAG。
  3. 页面会展示已有知识库卡片。

页面上能看到什么​

区域说明
搜索框按名称、描述或分组查找知识库
检索进入全局检索（NineClaw RAG）；右上角齿轮可打开 检索设置
+ 创建新建知识库
部署把知识库应用到 NineClaw 实例
知识库卡片展示名称、构建状态（右上角徽章）、文档数量、更新时间等

卡片右上角：五种构建状态​

列表卡片右上角只表示整个知识库的构建结果（由库内全部文档的解析结果汇总），不是单文件状态。
状态点与徽章采用红绿灯语义：绿 = 已就绪，黄 = 构建中 / 部分异常，红 = 构建失败。

状态（界面）API status含义什么时候会出现
待构建pending还没开始构建空库，或库内文档都还没开始解析
构建中building正在解析至少有一个文档仍在解析
已就绪success构建成功全部文档解析成功
部分异常part_success有好有坏有文档成功，也有文档失败
构建失败fail构建失败全部文档解析失败

使用建议：

  • 只有 已就绪（或至少关键文档已解析成功）时，问答和召回才比较稳定。
  • 出现 部分异常 / 构建失败 时，点进详情页看左侧文件树里哪几个文件失败，修好后点 重新解析。
  • 列表里只要还有库处于 构建中，页面会自动刷新状态，一般不用整页刷新。

不要和详情页左侧的单文件状态混看：文件树用的是「待解析 / 解析中 / 已解析 / 解析失败 / 无切片」；卡片右上角是上面这五种库级状态。

首次使用前检查 QYRAG​

如果 RAG 页面加载失败、没有知识库，或提示无法连接外部知识库服务，说明 QYRAG 尚未对接成功。请完整阅读并按步骤操作 QYRAG 配置（含 RAGFlow 侧配置与 NineClaw 设置 → 外部知识库）。

常见需要确认的信息：

配置项说明
服务地址QYRAG / RAGFlow 地址，通常为 http://<服务器地址>:8513
API KeyRAGFlow API Key（不是 DashScope Key，详见 QYRAG 配置文档）
测试连接在 NineClaw 设置页点击 测试连接 并 保存

详细填写步骤见 QYRAG 配置 第二节「NineClaw 外部知识库配置」，避免与本文重复维护。

创建知识库​

  1. 在 RAG 列表页点击 + 创建。
  2. 填写知识库名称和描述。
  3. 点击 创建。
  4. 创建成功后，点击卡片进入详情页上传文档。

上传与解析文档​

按下面五步即可把文件加入知识库：

  1. 进入某个知识库详情页。
  2. 左侧文件区点击 上传，选择文档 / 图片 / 音频 / 视频。
  3. 上传后该文件会进入 解析中；页面会自动轮询，一般无需手动刷新。
  4. 鼠标移到左侧某条文件上时，状态徽章与文件大小会换成 解析进度条（数值来自 RAGFlow，随轮询更新）。
  5. 左侧状态变为 已解析 后，中间可看预览，顶部 切片 按钮可点；未解析时 切片 为禁用（不可点）。
  6. 需要让智能体用这份资料时，回到列表页把知识库 部署 到运行中的实例。

区域功能
左侧文件树上传、搜索；单文件状态：待解析 / 解析中 / 已解析 / 解析失败 / 无切片。悬停行时状态与大小变为解析进度条（见下）
中间工作区打开文件并呈现文件本身：文本显示正文，PDF/图片内嵌预览，音视频只提供播放器
右侧面板知识问答、召回测试

文件行：悬停看解析进度​

详情页左侧每条文件默认显示 状态（如已解析）和 文件大小。把鼠标移到该行上时，这两项会换成 进度条 + 百分比。

你看到的说明
默认状态徽章 + 大小（如 12.7 KB）
鼠标悬停进度条与百分比，来自 RAGFlow 的 progress
条在走页面约每 3 秒 轮询文件列表，无需整页刷新
已解析后悬停进度一般为 100%；失败时进度条为红色

进度详情（progress_msg，含失败原因）可在悬停进度条时通过提示看到。若条长时间不动，按 常见排查 检查 QYRAG 解析服务。

支持的文件格式（RAGFlow / NineClaw）​

知识库底层是 RAGFlow（QYRAG）。能否解析以 RAGFlow 为准；NineClaw WebUI 上传框会再限制「可选扩展名」。用户查阅本表即可：
RAG — 支持的文件格式（本页锚点 #kb-supported-formats）。

NineClaw WebUI 可上传（与上传按钮一致）​

类型扩展名
文本.txt .md .markdown .json .csv .log
办公文档.docx .pdf
图片.png .jpg .jpeg .webp .gif .bmp .tif .tiff
音频.wav .mp3 .m4a .aac .flac .ogg .opus .wma
视频.mp4 .webm .mov .mkv .avi .wmv .flv .m4v

系统按文件扩展名区分音视频。请勿把 .mp4 改名为 .mp3 再上传。

说明： 详情页对 .doc（旧版 OLE）可做预览回退，但上传入口以上表为准；复杂旧版 Word 建议另存为 .docx 后再上传。

RAGFlow 官方还支持、WebUI 未全量开放的格式​

下列格式在 RAGFlow 控制台（http://服务器:8513）侧通常可解析（与官方 General 等切片模板兼容），但 NineClaw 知识库上传框当前不一定可选。若必须使用，可在 RAGFlow 控制台上传后，再在 NineClaw 使用该知识库（以交付约定为准）：

类型扩展名（RAGFlow 常见）
文档.doc .mdx .html .eml
表格.xlsx .xls
演示文稿.ppt .pptx

官方「切片模板 ↔ 兼容扩展名」与版本差异，请直接看 RAGFlow 文档：

  • Configure Dataset（切片模板与兼容格式）
  • Quickstart（支持的文件类型概述）

解析成功还依赖模型配置​

内容类型通常还需要
文本 / PDF / WordEmbedding；复杂 PDF 可能依赖 OCR / 视觉解析
图片Embedding + OCR / 视觉相关模型
音频 / 视频Embedding；稳定出切片时还需按交付配置 RAGFlow 解析相关模型（如 ASR）

对接见 QYRAG 配置；部署见 QYRAG 部署。

音频怎么用？​

知识库里的音频与文本一样走 RAGFlow 上传 + 解析。详情页中间区只播放音频，不再展示「转写内容」面板，也不会在预览时调用 Models / RAGFlow ASR 做前端转写。

步骤你做什么系统做什么
1上传 .mp3 / .wav 等音频文件进入 RAGFlow 知识库并触发解析
2点开该文件中间只呈现播放器（文件预览）
3解析成功后点 切片查看 RAGFlow 生成的向量切片；未解析时按钮禁用

若希望音视频在问答中可检索，需保证 RAGFlow 侧解析成功并产出切片。音视频在 RAGFlow 内能否顺利解析，取决于 RAGFlow「模型设置」中的解析相关模型（按交付环境配置；与 Models 页供应商 ASR 无关）。
Models 页的 ASR 面板仅用于供应商连通性试听，见 ASR 语音转写。

视频怎么用？​

视频同样只做文件呈现 + RAGFlow 解析。详情预览只保留播放器，无关键帧、无「转写内容」区。

步骤你做什么系统做什么
1上传 .mp4 / .webm 等视频上传到 RAGFlow 并解析
2点开该文件中间只播放视频
3解析成功后点 切片查看切片；未解析时 切片 不可点

失败时检查左侧文件状态，并点 重新解析；不要在预览区等待「后台转写」。

图片说明​

上传后由 QYRAG / RAGFlow 解析（通常依赖 OCR / 视觉模型）。若一直失败，请在 RAGFlow 侧确认已配置可用解析模型，再回到 NineClaw 查看文件状态。

Word 文档预览（.docx / .doc）​

中间工作区对 Word 类文件的预览与实例工作区一致：

格式预览方式
.docx高保真排版预览（接近原稿版式）
.doc（旧版 OLE）尽量转成可读正文；复杂排版可能有差异

若预览空白或报错：确认文件未损坏；.doc 可另存为 .docx 后重新上传。

查看切片​

文档解析后会被拆成多个切片。切片是知识库检索的基础。

  1. 选中已解析文件（左侧为 已解析）。
  2. 点击顶部 切片（未解析时按钮为禁用状态）。
  3. 查看每个切片的内容。
  4. 按需启用或停用某些切片。

如果某些内容不应该参与问答，可以停用对应切片。

切片里的图片（视觉解析）​

部分文档经视觉 / OCR 解析后，切片会带示意图：

界面表现说明
左图右文左侧为切片配图，右侧为文字内容
点击图片打开放大预览（可关闭后继续浏览其它切片）

图片由平台从 RAGFlow 代理加载。若图裂、空白：检查 QYRAG 是否可达、该切片是否含 image_id，并刷新页面重试。

知识问答​

  1. 在右侧面板选择 知识问答。
  2. 选择问答使用的模型。
  3. （可选）打开问答设置，配置 跨语言检索（见下）。
  4. 输入问题并发送。
  5. 查看回答和引用来源。

知识问答走 AgenticRAG（可多轮检索与证据判断，再生成带引用的回答）。回答质量同时受文档质量、切片效果和模型能力影响。与全局检索共用同一套 Agent，仅检索范围不同。

跨语言检索（问答 / 召回）​

详情页右侧 知识问答 与 召回测试 的设置中，可多选 目标语言（默认勾选 中文 + 英文）。该参数会传给 RAGFlow，用于跨语言检索场景（例如问题是中文、资料含英文）。

操作建议说明
默认即可多数中文知识库保持「中文 + 英文」即可
资料语种单一可只勾选对应语言，减少无关召回
仍找不到内容先确认文档已解析、切片已启用，再调整语言与问法

可选语言一般包括：中文、英文，以及西 / 法 / 德 / 日 / 韩 / 越 / 阿 / 土等（以页面选项为准）。

输入框历史（↑ / ↓）​

在知识问答、召回测试等输入框中：

按键作用
↑调出上一条本页发送过的内容
↓在历史记录中向后翻；或回到正在编辑的草稿

历史按页面上下文分开保存（详情页问答 ≠ 全局检索 ≠ 其它模块），互不串扰。开始手动改字后，会退出“浏览历史”模式。

设计说明（面向研发/交付）见产品指南：知识问答 / AgenticRAG。

召回测试​

召回测试用于检查“系统能不能找对资料”，它更偏调试知识库效果。

  1. 切换到 召回测试。
  2. （可选）在设置中配置 跨语言检索。
  3. 输入查询语句。
  4. 查看命中的切片和相似度。

如果召回结果不理想，可以检查文档是否解析完成、切片是否启用、问题表达是否和文档内容匹配，以及跨语言选项是否合适。

全局检索（NineClaw RAG）​

全局检索 = 在 RAG 列表页点击 检索 后进入的独立页面（标题为 NineClaw RAG）。它会按你选的模型，在多个知识库里检索资料并生成回答。

适合：部署前验证「多库一起问」是否可用。
不适合：只想调试某一个知识库时——那种请进该库详情页，用右侧 知识问答。

对比项全局检索（本页）详情页「知识问答」
入口RAG 列表 → 检索进入某个知识库详情 → 右侧 知识问答
覆盖范围默认全部知识库，可在 检索设置 里勾选仅当前这一个知识库
回答引擎同一套 AgenticRAG Agent同一套 AgenticRAG Agent
典型用途跨库问答、部署前联调单库效果调试

访问地址示例：http://xxx:8510/knowledge/search

1. 进入页面​

  1. 打开 NineClaw WebUI，进入左侧导航 RAG。
  2. 确认至少有一个知识库，且文档已解析完成。
  3. 点击列表页工具栏 检索。
  4. 进入 NineClaw RAG 页面。

页面主要分区：

位置界面元素作用
左上角返回有结果时先清空回到空白页；空白页再点则回 RAG 列表
页面中央标题 + 问题输入框 + 检索输入问题并开始 / 停止生成
右上角齿轮图标打开右侧 检索设置 侧栏（见下一节）

上图右侧即为 检索设置：首次使用建议先打开它，选好模型和知识库，再提问。

2. 检索设置（必看）​

点击页面右上角齿轮，右侧滑出 检索设置 侧栏（关闭可点侧栏右上角 ×）。侧栏里有两类配置：

配置项说明
问答模型下拉选择用于生成回答的模型（如图中的 modelstack / GLM-4-Flash）。若报错与工具调用相关，请换一个支持对话的模型。
知识库范围（默认全部）用开关勾选本次要参与检索的知识库。默认全部开启；关掉某个库后，该库不会参与本次问答。

操作建议：

  1. 点右上角齿轮，打开 检索设置。
  2. 确认 问答模型 已选中可用模型。
  3. 在 知识库范围 中保留需要的库（至少开启一个）。
  4. 点 × 关闭侧栏（设置会保留），回到中间输入框提问。

未打开过检索设置时，一般会使用默认模型与「全部知识库」；若问答失败或答非所问，优先回到这里检查模型和勾选范围。

3. 提问并查看回答​

  1. 在中间输入框填写问题（例如「中美贸易战为什么会打起来？」）。
  2. 点击输入框右侧的 检索。生成过程中按钮会变成 停止，可随时中断。
  3. 系统使用与详情页相同的 AgenticRAG Agent（可能多轮检索）。页面布局与时序如下：
    • 状态行会显示「正在检索并生成回答」以及 覆盖知识库（≤5 个全部列出；多于 5 个时显示前 3 个 + … + 最后一个）。
    • 上方先流式展示回答正文。
    • 回答全部流式完成（状态变为「回答完成」）之后，下方再逐条浮现 资料来源（不是一次性全部跳出）。
  4. 中途点 停止 时，只保留已生成的部分回答，不展示资料来源。

4. 查看引用与资料来源（角标联动）​

回答正文中的引用角标与下方 资料来源 列表编号一一对应。系统识别：

写法说明
[1]、[2]常见半角方括号（推荐）
［1］全角方括号
【1】中文方头括号（模型偶发写法，同样可点）

越界幻觉角标（编号大于资料来源数量，且 ≤50）会被自动去掉，不会变成可点按钮。

  1. 点击正文角标，或点击某条资料来源摘录：滚动定位到对应来源（不铺彩色背景）。
  2. 在来源卡片上点击 打开原文切片：进入对应知识库详情，并尽量定位到相关文件 / 切片（此时切片会高亮背景色）。
  3. 在详情页左上角点返回：
    • 未刷新页面 → 回到刚才的全局检索回答页；
    • 已刷新页面 → 回到空白的 NineClaw RAG 页。

须等回答正文流式全部结束后，资料来源才会开始逐条出现。中途点 停止 时仍不展示资料来源。

5. 返回与刷新​

你的操作页面结果
有回答时，在检索页点左上角 返回清空本次结果，回到居中空白检索页
已在空白页再点 返回回到 RAG 列表
刷新浏览器回到空白检索页（不保留上次回答）
从引用进详情再返回（未刷新）恢复刚才的问题、回答与资料来源

Web Search 列表页也有跨信源的全局检索，见 Web Search（信源管理）。MCP 没有全局检索。

部署到 NineClaw 实例​

部署前请确认目标实例处于 运行中。

  1. 在 RAG 列表页点击 部署。
  2. 选择要部署的知识库（例如「策略分析」）。
  3. 选择一个或多个 运行中 的 NineClaw 实例。
  4. 点击 开始。
  5. 等待部署完成（状态变为「已部署」）。

部署完成后，目标实例中的智能体才能在任务中使用这些知识库。

部署写入了什么？​

Manager 会把 QYRAG 相关配置写入实例的 /opt/data/.env（Hermes 环境变量），其中包括：

变量含义
QYRAG_BASE_URLQYRAG / RAGFlow 服务地址
QYRAG_API_KEY访问 QYRAG 的 API Key
QYRAG_DATASETS知识库名称 → dataset id 的 JSON 映射

QYRAG_DATASETS 的键是知识库显示名称，值是对应的 dataset id。目标效果示例：

QYRAG_DATASETS="{\"策略分析\": \"afe3d03a863811f181aba75879343158\"}"

为何有时仍看到 \u7b56\u7565\u5206\u6790？ Hermes 的 PUT /api/env 写入 .env 时会丢掉中文（变成空键 ""）。Manager 在部署时会再通过容器内 UTF-8 回写该行，因此需部署含此回写逻辑的 Manager，并对实例重新部署知识库后，cat .env 才会显示可读中文。

如何确认部署成功​

  1. 打开目标 NineClaw 实例详情页，点击右上角 容器终端。
  2. 执行：
cd /opt/data
cat .env
  1. 确认存在 QYRAG_DATASETS，且键为知识库中文名。正常示例：
QYRAG_DATASETS="{\"策略分析\": \"e1aaa1d285a911f1a842176ee66dcb4b\"}"

若仍看到 QYRAG_DATASETS="{\"\": \"...\"}"（空键），说明写入了旧结果：请确认 Manager / WebUI 已更新，并对该实例重新部署一次。 若看到 \u7b56\u7565\u5206\u6790 这类转义，也是旧写入格式；重新部署后应变为直接中文。

常见排查​

现象优先检查
RAG 页面加载失败QYRAG 服务地址和 API Key 是否正确
卡片一直是 构建中进详情看哪个文件仍在解析；QYRAG 解析服务是否正常；稍等自动刷新即可
卡片是 部分异常 / 构建失败进详情查看失败文件 → 修好后 重新解析；全部成功后卡片应变为 已就绪
单文件一直「解析中」QYRAG 文档解析是否正常；详情页会自动变为「已解析」，无需整页刷新
悬停看不到进度条 / 百分比一直是「—」是否把鼠标放在文件行上（不是只点名称）；Manager 是否返回 progress；稍等轮询或刷新 WebUI
进度条长时间不涨RAGFlow 解析是否卡住；可点该行右侧 重新解析；并核对 8513 侧解析日志
详情页状态与 8513 不一致稍等自动轮询；仍不对时刷新 WebUI，并确认 Manager 已更新
切片 按钮点不了当前文件是否已解析成功；未解析时按钮故意禁用
音视频只能播、没有正文区属预期：预览只呈现文件（播放器），解析结果请到 切片 查看
音视频解析失败 / 无切片RAGFlow 解析模型是否按交付要求配置；左侧点 重新解析
图片无法选择 / 上传刷新 WebUI；确认扩展名在 支持的文件格式 内（png/jpg/webp 等）
上传框选不到 xlsx / pptWebUI 未全量开放；可查 支持的文件格式 第二节，或到 RAGFlow 控制台上传
图片上传后解析失败QYRAG 是否已配置 OCR/视觉解析模型
问答没有引用文档是否解析完成，切片是否启用；卡片是否至少接近 已就绪
召回结果不相关文档内容、问题表述、切片状态是否匹配；可调整 跨语言检索
切片有图裂 / 点不开放大QYRAG 是否可达；刷新后重试；确认切片含视觉图
Word 预览空白文件是否损坏；.doc 可另存为 .docx 再上传
全局检索按钮不可用是否至少有一个知识库
全局检索失败 / 无回答问答模型是否已选、知识库是否勾选、文档是否已解析
全局检索无资料来源是否中途点了停止；回答是否已流式完成（未完成前不展示）；是否已召回到切片
资料来源比回答先出现请更新 WebUI：当前版本须等正文流式结束后再逐条展示来源
角标点不了 / 像普通文字是否为 【n】 等写法（已支持）；编号是否超出资料来源数量（幻觉角标会被去掉）；刷新 WebUI
角标与资料来源对不上 / 点了没高亮角标编号应与资料来源 [n] 一致；刷新 WebUI / 重启 Manager
点「打开原文切片」后切片不高亮文档是否已解析出真实向量切片；可稍后在详情页「切片」中再点角标重试
NineClaw 有多个库，8513 /datasets 只有少量账号不一致： NineClaw 列出的是「外部知识库」API Key 所属用户的库；浏览器登录 8513 若是另一账号，只能看到该账号下的库。用生成 Key 的同一账号登录 8513 核对
点引用进详情后返回不对是否刷新过页面；刷新后会话会清空
实例中无法使用知识库是否已部署到目标实例
.env 中 QYRAG_DATASETS 键为空 ""是否为旧版本写入；更新后重新部署；正常应为中文名称
