部署要求

部署 NineClaw + QYRAG（RAGFlow） 前，请先对照本文软硬件与网络要求。

  • 只部署 NineClaw、暂不用知识库： 重点核对 Docker 环境与 8510 端口，然后进入 系统部署。
  • 需要使用知识库： 除 NineClaw 外，还需 QYRAG 在 8513 端口可用。先 QYRAG 部署，再 QYRAG 配置 完成对接。

先看这三项​

类别你需要确认什么
软件Linux、Docker Engine ≥ 24.x、Docker Compose ≥ v2.30；GPU 场景还需 NVIDIA 驱动与 CUDA
硬件CPU、内存、GPU、磁盘满足生产参考配置（或交付方确认的规格）
网络放通 8510（NineClaw）、8513（QYRAG）；NineClaw 能访问 QYRAG

软件环境​

按下面两张表逐项核对。每张表只出现一次，可直接复制「检查命令」在服务器上验证。

必装组件（所有环境）​

组件最低版本检查命令
操作系统Ubuntu ≥ 20.04 或 CentOS ≥ 8cat /etc/os-release
系统架构amd64 / x86_64uname -a
Docker Engine≥ 24.xdocker version
Docker Compose≥ v2.20docker compose version

GPU 与 AI 运行时（使用本地 GPU 时）​

以下组件在文档解析、向量化、本地模型推理等 GPU 场景下需要；若知识库与模型均走云端 API，以交付包说明为准。

组件最低版本检查命令
NVIDIA Driver≥ 580nvidia-smi
nvidia-container-toolkit无固定版本要求nvidia-ctk --version
GLIBC≥ 2.28strings /usr/lib64/*.so.* | grep GLIBC
GLIBCXX≥ 3.4.25strings /usr/lib64/*.so.* | grep GLIBCXX
CUDA≥ 12.9nvidia-smi
vLLM≥ 0.17.0docker images | grep vllm

怎么判断要不要装 GPU 相关组件？

  • 需要在本地跑 QYRAG 向量化、Embedding 或推理 → 必须核对上表。
  • 仅部署 NineClaw 管理面，模型与知识库全部调用云端 → 重点确认 Docker 与网络即可。

硬件环境​

下表为生产环境参考配置（参考机型：Intel Xeon Gold 6230R、1024GB 内存、A800 × 8、16T 硬盘等）。实际采购可按业务规模在最低要求上调整，以交付方最新说明为准。

配置项参考示例指标要求
CPUIntel Xeon Gold 6230R @ 2.10GHz第四代 / 第五代 Intel Xeon Scalable 双路，每颗 ≥32 核，主频 ≥2.0GHz
内存1024GB≥1024GB DDR5，频率 ≥4800MHz，支持 ≥32 个内存插槽
GPUNVIDIA A800 × 8最低 2 张 A800 80G，可扩展至 8 张 A800 80G
硬盘16T 企业级≥2×16T 企业级 HDD（≥7200 转）；≥2×960GB 读密集型 SATA SSD；≥2×3.84TB 读密集型 PCIe 4.0 NVMe SSD（U.2）
RAID—独立 RAID 1G 阵列卡，支持 RAID 0 / 1 / 5 / 6 / 10
网口—≥2 个万兆 SFP+ 光口；≥4 个千兆 RJ45 电口
电源—≥4 个 2700W 冗余热插拔钛金电源，支持 N+N 或 N+M 冗余

各组件在系统中的用途：

配置项主要作用
CPU + 内存支撑 NineClaw 多服务、QYRAG 文档解析与检索并发
GPUQYRAG 向量化、模型推理等 AI 负载；卡数越多，并发与吞吐越高
硬盘分层HDD 存大量文档，SSD / NVMe 存热数据与系统；需预留镜像和业务增长空间
RAID / 网口 / 电源保障数据可靠性与机房级冗余

网络端口​

端口用途是否必开
8510NineClaw WebUI、文档、Manager API是
8513QYRAG / RAGFlow API使用知识库时
8511Traefik 管理按需

防火墙需允许：

  • 用户浏览器 → 8510
  • NineClaw → 8513（QYRAG 若在其他机器，改为对应 IP）

部署前核对清单​

按顺序打勾，全部完成后再执行安装。

软件

  • 操作系统与架构符合要求
  • Docker Engine ≥ 24.x，Docker Compose ≥ v2.20
  • 已安装 whiptail（NineClaw ./deploy.sh）
  • GPU 场景：NVIDIA Driver ≥ 580、CUDA ≥ 12.9、nvidia-container-toolkit 可用

硬件

  • CPU、内存、GPU、磁盘满足上表或交付方确认的配置
  • RAID、网口、电源满足机房与冗余要求

网络与交付物

  • 端口 8510 / 8513 已放通
  • 已拿到 NineClaw、QYRAG 交付包
  • 若用云端大模型，服务器可访问 DashScope 等 API
