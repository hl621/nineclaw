QYRAG 配置

要用 NineClaw 的知识库功能，需要先准备好 QYRAG（RAGFlow） 这套后台服务，再让 NineClaw 连上去。

在哪里操作地址干什么
RAGFlowhttp://<服务器地址>:8513上传文档、解析切片、做检索（后台服务）
NineClawhttp://<服务器地址>:8510日常在 WebUI 里管理知识库（你主要用的界面）

一句话： 你在 NineClaw 页面点按钮；真正处理文档的是 QYRAG。两边各自安装，用 地址 + API Key 连起来即可。

开始之前：确认 QYRAG 已安装​

本文讲的是 QYRAG 安装完成之后的对接配置，不包含 QYRAG 本身的安装步骤。

情况怎么做
浏览器能打开 http://<服务器地址>:8513直接进入下方配置流程
8513 无法访问先按 QYRAG 部署 完成安装；若无交付包，联系交付或运维人员
暂不使用知识库可跳过本文，后续需要时再配置

软硬件与端口要求见 部署要求（8513 端口、NineClaw 能访问 QYRAG）。

对接完成后你要做的事：

  1. RAGFlow 侧（8513） — 注册登录、配好模型、生成 RAGFlow API Key
  2. NineClaw 侧（8510） — 设置 → 外部知识库，填地址和 Key，测试连接后保存
  3. RAG 页面 — 创建知识库、上传文档；若要让智能体也能查文档，再把 RAG 部署 到 NineClaw 实例

配置流程概览​

确认 QYRAG 已在 8513 运行
    → 注册 / 登录 RAGFlow
        → 配置 Qwen 模型（OpenAI 兼容接口）
            → 生成 RAGFlow API Key
                → NineClaw「外部知识库」填写地址与 Key
                    → 测试连接并保存
                        → 在 RAG 页面创建知识库

一、RAGFlow 控制台配置（8513）​

浏览器打开：http://<服务器地址>:8513（将 <服务器地址> 替换为实际 IP 或域名）。

步骤 1：注册账号​

首次使用请点击登录页右下角 「注册」。

字段填写说明
邮箱填写可用邮箱，作为登录账号
名称填写显示名称
密码设置登录密码

填写完成后点击 「继续」。若已有账号，点击 「已经有帐户？登录」 跳到步骤 2。

步骤 2：登录​

在登录页输入邮箱和密码，点击 「登录」。

登录成功后会进入 工作区 首页（知识库、聊天、搜索等入口）。

步骤 3：进入模型配置页​

在左侧菜单点击 「模型提供商」（部分版本显示为 「模型」），或直接访问：

http://<服务器地址>:8513/user-setting/model

页面分为三块：

区域说明
设置默认模型（左上）为 LLM、Embedding 等任务选择默认模型
已添加的模型（左下）显示已配置成功的模型实例
可选模型（右侧）各厂商模型卡片，可点击 添加

步骤 4：添加 Qwen（OpenAI 兼容接口）​

QYRAG 使用阿里云 通义千问 Qwen 时，需通过 OpenAI-API-Compatible 方式接入 DashScope 兼容端点。

4.1 在右侧 可选模型 列表中找到 OpenAI-API-Compatible（或名称含 OpenAI 兼容的卡片）。

4.2 点击该卡片上的 「添加」，在弹出菜单中选择 「LLM」。

4.3 在弹窗中填写以下信息：

字段填写内容
实例名称Qwen（可自定义，便于识别）
API-Key你的 DashScope API Key，格式如 sk-xxxxxxxx（见下方获取方式）
Base-Urlhttps://dashscope.aliyuncs.com/compatible-mode/v1

如何获取 DashScope API Key

  1. 登录 阿里云百炼控制台
  2. 在控制台创建并复制 API Key
  3. 更多说明见 Qwen 官方文档

注意： 请勿将 API Key 提交到代码仓库或截图外传；文档示例统一写作 sk-your-dashscope-api-key。

4.4 点击左下角 「验证」，确认连接成功后点击 「确认」 保存。

步骤 5：关联默认模型​

保存成功后：

  1. 在左下 「已添加的模型」 区域可看到刚添加的 Qwen 实例。
  2. 回到左上 「设置默认模型」，在 *LLM 下拉框中选择刚添加的 Qwen 模型。
  3. 若需使用知识库向量化，在 Embedding 等字段选择对应模型（按交付环境要求配置）。
  4. （可选） 若交付环境要求音视频在 RAGFlow 内稳定解析出切片，可按需配置 默认 ASR 等解析相关模型。
    • WebUI 知识库详情预览只播放文件，不在预览区做 ASR 转写展示。
    • 日常上传与预览步骤见 RAG — 音频 / 视频。

完成本步后，RAGFlow 内部的对话、文档解析等能力才能正确调用已配置的模型。

步骤 6：生成 RAGFlow API Key​

NineClaw 连接 RAGFlow 需要 RAGFlow 自身的 API Key（与步骤 4 中的 DashScope Key 不同，请勿混淆）。

6.1 在左侧菜单点击 「API」，或访问：

http://<服务器地址>:8513/user-setting/api

页面上方会显示 API 服务器 地址，例如 http://<服务器地址>:8513，请记下该地址，下一步 NineClaw 配置要用。

6.2 点击 「API KEY」 按钮，在弹窗中点击 「创建新密钥」。

6.3 生成后，在 Token 列复制完整密钥（通常只显示一次，请立即保存）。

需要保存的信息示例
RAGFlow 服务地址http://<服务器地址>:8513
RAGFlow API Keyragflow-xxxxxxxx（以实际生成为准）

二、NineClaw 外部知识库配置（8510）​

RAGFlow 配置完成后，回到 NineClaw 建立连接。

步骤 7：填写外部知识库​

7.1 浏览器打开 NineClaw WebUI：

http://<服务器地址>:8510

7.2 点击左下角 「设置」，在左侧选择 「外部知识库」。

7.3 填写连接信息：

字段填写内容
服务地址与 RAGFlow API 服务器一致，例如 http://<服务器地址>:8513
API Key步骤 6 中生成的 RAGFlow API Key

7.4 点击 「测试连接」。显示成功后点击 「保存」。

保存后立即生效。此时可进入左侧 RAG（知识库） 页面创建知识库、上传文档。详细操作见 RAG（知识库）。

上传前请先确认格式： NineClaw / RAGFlow 支持哪些扩展名，见 RAG — 支持的文件格式（含 WebUI 可上传列表、RAGFlow 官方额外格式，以及官方文档链接）。

两种 API Key 的区别​

配置过程中会涉及两把不同的 Key，请勿混用：

类型在哪里配置用途
DashScope API KeyRAGFlow → 模型配置 → OpenAI 兼容 → Qwen让 RAGFlow 调用通义千问大模型
RAGFlow API KeyNineClaw → 设置 → 外部知识库让 NineClaw Manager 访问 RAGFlow 知识库 API

完成检查​

  • http://<服务器地址>:8513 可打开 RAGFlow 并登录
  • 模型页已添加 Qwen（OpenAI 兼容），且 验证 通过
  • 默认 LLM 已关联到 Qwen
  • （推荐）默认 Embedding 已配置，文档才能稳定向量化
  • （按交付需要）音视频要稳定产出切片时，已按环境配置 RAGFlow 解析相关模型（如 ASR）
  • 已生成并保存 RAGFlow API Key
  • http://<服务器地址>:8510 外部知识库 测试连接 通过
  • RAG 页面可创建知识库并上传文档；卡片状态可见（待构建 / 构建中 / 已就绪 / 部分异常 / 构建失败）
  • 如需在实例中使用，已将 RAG 配置 部署 到目标 NineClaw 实例

常见问题​

现象处理建议
8513 端口打不开QYRAG 可能尚未安装，联系交付或运维；参见本文「开始之前」
模型验证失败检查 DashScope API Key 是否有效、Base-Url 是否为 https://dashscope.aliyuncs.com/compatible-mode/v1
NineClaw 测试连接失败确认服务地址带 http:// 且端口为 8513；API Key 为 RAGFlow Key，不是 DashScope Key
RAG 页面无法加载知识库检查外部知识库设置是否已保存；Manager 是否能访问 8513 端口
RAG 页面列表为空外部知识库是否已保存且测试连接通过
NineClaw 有多个知识库，8513 页面只有少量NineClaw 列表来自「外部知识库」里的 RAGFlow API Key 所属用户；浏览器登录 8513 若是另一账号，只能看到该账号下的库。请用生成该 Key 的同一账号登录 8513 核对
上传图片后解析失败QYRAG 是否已配置 Embedding / OCR（视觉）相关模型；支持格式见 RAG — 支持的文件格式
音视频能播但点不了切片 / 无切片文件是否已解析成功；RAGFlow 解析是否产出切片；详见 RAG — 音频
上传格式灰掉 / 选不了是否在 WebUI 支持列表内；Excel/PPT 等见 支持的文件格式 第二节
预览区没有「转写内容」属预期：详情预览只呈现文件；解析结果看 切片
上传后一直未解析回到 RAGFlow 检查 Embedding / 解析模型是否已配置
召回结果为空文档是否已解析完成，切片是否启用，检索参数是否过严
Runtime 中无法使用知识库是否已把 RAG 配置部署到目标实例；在实例终端检查 /opt/data/.env 中 QYRAG_DATASETS 是否为「名称 → id」（不应出现空键 ""），必要时重新部署

对接完成后，在 NineClaw 的日常问答（详情页「知识问答」与列表页「全局检索」）使用同一套 AgenticRAG，详见 RAG（知识库）。
