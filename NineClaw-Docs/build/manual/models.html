Models管理

Models 页面用于接入与管理大模型供应商，分两步使用：

  1. 添加供应商 — 填写 Base URL、API Key 等，登记到平台资源库；
  2. 部署到实例 — 选择 WebUI 中 运行中 的 Runtime 实例，让对话真正能调用模型。

添加供应商时 不需要 已有实例；部署时 必须 有 运行中 的实例（在 NineClaw 页面创建）。这与 deploy.sh 启停的平台服务不是同一层，见 概览。

首次初始化顺序：添加供应商 → 创建实例 → 部署模型（见 系统部署 — 第五步）。

访问地址示例：http://xxx:8510/models

进入页面​

  1. 打开 NineClaw WebUI。
  2. 在左侧导航中点击 Models。
  3. 页面会展示已有模型供应商卡片。

页面上能看到什么​

区域说明
搜索框按名称、地址或模型名查找供应商
+ 添加新增模型供应商
对比打开多模型对比（仅 LLM / VLM）
部署把模型配置应用到一个或多个 NineClaw 实例
Provider 卡片展示供应商名称、启用状态和连通状态

健康状态用于判断模型服务是否可访问：

状态含义
在线服务可达
异常服务有响应，但返回结果不符合预期
离线服务不可达或连接超时
未检测暂时还没有检测结果

添加模型供应商​

  1. 点击 + 添加。
  2. 填写供应商名称。
  3. 填写 Base URL，通常是模型服务的 OpenAI 兼容地址，例如 https://api.example.com/v1。
  4. 填写 API Key。
  5. 点击 获取，让系统读取该供应商提供的模型列表。
  6. 勾选要纳入管理的模型，并确认模型类型（系统会按名称自动推断，也可按需调整）。
  7. 点击 保存。

重要：获取后默认全部未开启。
点击 获取 后，新拉到的模型名称默认是 关闭（未勾选） 状态，不会自动全选。请按需手动打开要用的模型，再 保存。
再次 获取 时：以前已开启的会保持开启；新出现的模型仍默认关闭。可用「隐藏未开启」只看已勾选的模型。

字段说明
名称给供应商起一个易识别的名字，例如 OpenAI、DeepSeek、模型栈
Base URL模型服务地址，需要和供应商提供的地址一致
API Key调用模型服务所需密钥
模型类型区分 LLM、Embedding、VLM、ASR、TTS、Rerank；详情页会按类型切换不同调试面板

如果点击 获取 失败，优先检查 Base URL、API Key、服务器网络和供应商服务状态。

「目录」与「已开启」不要混淆​

概念含义
完整目录在添加 / 编辑供应商时点击 获取，从上游 /v1/models 拉到的全部模型
已开启你勾选并写入供应商配置的模型；详情页调试、部署、多模型对比都只使用这些模型

对比弹窗不会再拉上游完整目录，也不会自动开启未配置的模型。若列表里找不到某个 LLM / VLM，请先到对应供应商详情页开启并保存，再回到对比页添加。

模型类型说明​

类型用途详情页调试方式
LLM文本对话、主模型输入问题，流式查看回答
VLM图文多模态上传或 Ctrl+V 粘贴图片后提问
Embedding文本向量化最多 10 段文本 → 向量 → PCA 图 / JSON
ASR语音转文字仅支持上传音频转写，见 ASR 语音转写
TTS文字转语音输入文本、选择音色，合成并播放
Rerank检索重排查询 + 最多 10 条候选文档，按相关性打分排序

左侧模型旁会显示类型标签，以及能力提示（可体验 / 受限 / 不可用）。不可用模型通常无法走当前 HTTP 调试面板（例如 Realtime、MiniMax TTS 等），请按提示换模型。

编辑模型供应商​

  1. 在供应商卡片上点击 编辑。
  2. 修改名称、Base URL 或模型选择。
  3. 如果需要重新读取模型列表，再次点击 获取。
  4. 点击 保存。

编辑时如果不想修改密钥，可以保持 API Key 为空。

测试模型（详情页 Playground）​

  1. 点击供应商卡片进入详情页。
  2. 在左侧选择或启用要测试的模型，并确认类型正确。
  3. 右侧按类型切换调试面板。
  4. 按面板提示操作，观察结果是否正常。

LLM 文本对话​

  1. 选中类型为 LLM 的模型。
  2. 在输入框提问并发送，右侧流式展示回答。
  3. 可复制、重新生成等（与对话面板一致）。清空 按钮在输入框右侧、发送按钮旁（与其它对话输入区布局一致）。
  4. 可用键盘 ↑ / ↓ 翻看本页最近发送过的内容（与 RAG 输入历史 相同约定）。

部分思考型模型（如 Qwen3）在 Playground 中会默认关闭「思考过程」输出，优先保证界面直接看到正文回答。

VLM 图文多模态​

  1. 选中类型为 VLM 的模型。
  2. 用 图片上传 按钮选择本地图片，或 Ctrl+V 把剪贴板图片粘贴到对话框（不必先点进输入框）。
  3. 支持多张（常见格式 png / jpeg / webp / gif / bmp；单张约 10MB 内、总数有上限）；发送前会自动规范为上游更易接受的 JPEG。
  4. 日常闲聊/看图请优先用通用 VL（名称含 vl / vision，且不含 ocr）。

OCR 专用模型（如 qwen-vl-ocr-*）对图片宽高要求更严，小图或随意截图容易失败；页面会标为「受限」。文档扫描、票据识别场景再选用 OCR 模型。

Embedding 文本向量​

当选中类型为 Embedding 的模型时：

文档区（上方）

操作说明
条数上限最多 10 条；右上角显示 当前条数/10（如 5/10）
批量输入按钮 → 弹窗：按行粘贴多段文本，点「添加」追加到列表（空行忽略）
添加文本追加一条空输入
清空清空全部文档（含默认示例），只留一条空输入
序号每条左侧显示 1、2、3…，与 Rerank 列表一致

满 10/10 时，「批量输入」与「添加文本」不可用；删掉若干条后可再添加。

输出区（下方）

  1. 点击发送（至少 2 段非空文本），调用供应商 /embeddings。
  2. 在 图表 查看 PCA 分布（点越近语义越相近；悬停可看原文，贴边时提示会自动避让）。
  3. 可切换 JSON 并一键复制。
  4. 中间 调整 可拖动上下区域高度；文档变多时会尽量抬高文档区，避免末条被图表挡住。

Embedding Playground 只验证 embedding 模型本身。知识库文档向量由 RAG 上传解析时构建；文档召回请到 RAG（知识库） 详情页的「召回」测试。

Rerank 检索重排​

当选中类型为 Rerank 的模型时：

  1. 在顶部输入 查询（Query），点右侧发送运行重排。
  2. 在 文档 列表填写候选文本（左侧有序号，样式与 Embedding 一致）。
  3. 工具栏与 Embedding 相同约定：
    • 右上角 当前/10 计数；最多 10 条；
    • 批量输入 弹窗按行追加；添加文本 增一行；
    • 清除 清空全部文档（含默认示例），留一条空输入。
  4. 界面不再显示 Top N；系统固定对列表中最多前 10 条打分并排序（因列表本身最多 10 条，即对全部有效文档打分）。
  5. 每条下方显示相关性分数条、排序与分数。

智算云 / Paratera 等网关上的 GLM-Rerank 已走专用接口，一般无需手工改 URL。若分数异常，确认模型类型为 Rerank，且供应商在线。

ASR 语音转文字​

当选中类型为 ASR 的模型时：

  1. 上传本地音频（wav / mp3 / m4a / webm 等）；较长音频会自动分段后合并结果。
  2. 查看转写文本，可一键复制。

当前面板不提供在线录音，也不再暴露语言参数 / View Code。详细格式与推荐模型见 ASR 语音转写。

避免名称含 realtime 的 ASR（仅 WebSocket，HTTP 面板不可用）。

说明： 这里只验证供应商 ASR 是否连通。知识库详情页对音视频只播放文件，不走本面板，见 RAG — 音频。

TTS 文本转语音​

当选中类型为 TTS 的模型时：

  1. 选择音色（百炼 Qwen-TTS 推荐 Cherry；也可按模型说明添加音色名）。
  2. 输入要合成的文本。
  3. 点击合成并播放 / 下载。

稳定推荐（百炼 / DashScope）：

建议说明
使用 qwen-tts / qwen3-tts-flash 等走平台已适配的合成路径
音色用 Cherry 等官方音色兼容性最好
不要选 MiniMax/speech-*百炼兼容模式下不可用，页面会标「不可用」并禁用提交
不要选名称含 realtime 的 TTS仅 WebSocket，当前面板不支持

使用阿里云百炼时，请确认 Provider Base URL 与 API Key 同属北京站（dashscope.aliyuncs.com）或国际站（dashscope-intl.aliyuncs.com），且控制台已开通对应语音产品。

多模型对比​

在列表页点击 对比（或对比页底部 添加模型），打开「添加对比模型」弹窗：

能力说明
列表范围各已启用服务商里已开启的模型，且仅 LLM / VLM（Embedding、ASR、TTS、Rerank 不出现）
类型标识每行显示 服务商 / 模型名，并带 LLM / VLM 标签；可用类型筛选
服务商筛选下拉含全部服务商（禁用项会标注）；选禁用服务商时左侧为空并提示
混选对比LLM↔LLM、VLM↔VLM、LLM↔VLM 均可同屏做文本对比
带图对比仅当已选 ≥ 2 个模型且全部为 VLM 时，输入区「清空」右侧出现 上传本地照片，并支持 Ctrl+V 粘贴图片

对比页用法：

  1. 添加要对比的模型（建议至少两个，便于并排对照）。
  2. 纯文本：在底部输入同一个问题并发送；混选 LLM 与 VLM 时同样只发文本。
  3. 带图（全 VLM）：先确保已选 ≥ 2 且全是 VLM，再上传或 Ctrl+V 粘贴图片，然后提问（也可只发图，系统会用默认看图提示）。
  4. 系统并发请求各模型，并排展示回答；卡片底部可见 tokens、耗时、速度，以及 类型标签 + 服务商 / 模型名。

对比结果卡片布局：

区域说明
顶部状态点与「完成 / 生成中」等；悬停可复制回答或重新生成
中部模型回答正文（用户气泡可带图片缩略图）
底部左侧为输出/输入 tokens、耗时、速度；右侧为类型、Provider、模型名称

带图入口何时出现： 已选模型少于 2 个，或其中混入了 LLM，输入区不显示上传 / 粘贴图文能力，此时只能文本对比。若需要单模型带图调试，请到供应商详情页的 VLM 面板（任意单个 VLM 即可上传 / Ctrl+V）。离开「≥2 且全 VLM」条件时，对比页未发送的待传图片会被清空。

推荐选型（减少报错）​

面向日常体验，可按下面组合配置（名称以你供应商实际目录为准）：

能力更稳妥的选择请避开
LLMqwen3-8b、GLM-5.x 等通用对话模型把 Embedding / ASR / TTS 误标成 LLM
VLM通用 VL（如 ERNIE-VL、Qwen2.5-VL）OCR 专用模型用于闲聊看图
Embedding名称含 embedding / bge 的模型—
RerankGLM-Rerank、名称含 rerank 的模型—
ASRGLM-ASR-*、qwen3-asr-flash-*（上传真实语音）*realtime* ASR
TTSqwen-tts* + 音色 CherryMiniMax/speech-*、*realtime* TTS

同一供应商下也可以只开启你真正要用的几类模型，详情页更清爽。要参与对比的 LLM / VLM 必须先在供应商里开启并保存。

部署到 NineClaw 实例​

模型供应商保存后，只是进入了平台资源库，实例还不能用来对话。要让 Runtime 实例使用模型，必须完成部署。

部署前请确认目标实例已处于 运行中。若尚未创建实例，请先到 NineClaw 创建。

  1. 在 Models 列表页点击 部署。
  2. 选择要部署的供应商。
  3. 选择一个或多个 运行中 的 NineClaw 实例。
  4. 选择主模型。
  5. 如有需要，展开辅助模型配置，为视觉、网页抽取、压缩等任务指定模型。
  6. 点击 开始，等待部署完成。

部署完成后，打开目标实例 WebUI 做一次对话测试，确认模型已经生效。

若要在同一实例里让多个已部署模型协同回答（参考模型并行分析 + 聚合模型汇总），请到实例内配置 模型栈（MoA），见 NineClaw — 配置模型栈（MoA）。模型栈不会替代本页的供应商登记与部署，而是基于已部署到实例的模型做组合。

注意： 实例「模型栈」里若没有保存任何启用预设，对话模型下拉里不会出现 Mixture of Agents；需先新增预设并保存。

注意事项​

场景说明
供应商未启用未启用的供应商不会参与部署；对比里可选该服务商，但不会列出其模型
对比缺模型模型须已在供应商中开启且类型为 LLM / VLM
对比看不到上传图片须已选 ≥ 2 个模型且全部为 VLM；混入 LLM 或只选 1 个时仅支持文本
实例未运行部署时通常不能选择停止状态的实例
API Key 错误可能导致获取模型失败或对话失败
部署后未生效确认是否部署到正确实例，并等待实例完成重新加载
模型类型选错Embedding / TTS / ASR / Rerank 不会走普通对话面板，需在详情页选对类型
Embedding / Rerank 文档条数两面板均最多 10 条；满额后须先删除或清空才能再添加

常见排查​

现象优先检查
获取模型失败Base URL、API Key、模型服务网络是否正确
健康状态离线模型服务是否启动，服务器是否能访问该地址
对比列表很少目标 LLM / VLM 是否已在供应商详情页开启；服务商是否启用；类型筛选是否过窄
对比无法贴图是否已选 ≥ 2 且全是 VLM；混选 LLM 时请改用详情页 VLM 面板
对比测试无返回模型是否可用、供应商是否在线；思考型模型是否长时间无正文
实例中无法使用模型是否完成部署，主模型是否已选择
Embedding 无向量类型是否为 Embedding；是否至少 2 段非空文本；上游是否支持 embeddings
Embedding / Rerank 无法再添加是否已达 10/10；可删行或清空后再加
Rerank 失败 / 无分数类型是否为 Rerank；查询与文档是否已填；智算云类网关是否走平台已适配路径
ASR 无文字是否上传了真实语音（静音/合成音可能空文本）；模型是否含 realtime
TTS 合成失败是否误选 MiniMax/speech-*；音色是否为 Cherry 等；Base URL 区域是否与 Key 匹配
