ASR 语音转写

Models 详情页中的 ASR 面板用于验证「语音 → 文字」：上传本地音频，由供应商 ASR 模型转写，并支持复制结果。

同一入口下的 TTS（文字 → 语音）说明见 Models管理 — TTS。

和知识库音频不要混用

场景在哪里操作做什么
本页（Models ASR）Models → 供应商详情 → ASR 面板用供应商 ASR 试听转写（连通性验证）
知识库音 / 视频RAG → 某知识库 → 上传并打开文件只预览播放文件；解析成功后用 切片 查看内容

在 Models 里测通 ASR，不会接到知识库详情预览。知识库音视频操作见 RAG — 音频 / 视频。

当前能力范围​

支持不支持（已调整）
上传本地音频并转写浏览器在线麦克风录音
较长音频自动分段后合并面板内语言参数下拉
复制转写文本View Code 示例区

若你仍看到旧文档中的「在线录音 / 麦克风权限」说明，以本页与线上界面为准：只需上传文件即可完成体验。

操作步骤​

  1. 打开 Models → 进入已启用的供应商。
  2. 左侧开启并选中类型为 ASR 的模型（如 GLM-ASR-2512、qwen3-asr-flash-2026-02-10）。
  3. 右侧点击上传，选择音频文件（常见格式：wav / mp3 / m4a / webm 等）。
  4. 等待转写完成，查看文本，需要时点击 复制。

供应商需已启用。百炼请优先使用 Qwen-ASR（名称含 asr、不含 realtime）；智算云 / 兼容 OpenAI 转写的供应商可用对应 ASR（如 GLM-ASR-*）。

音频与结果说明​

  • 请用真实语音样本验证。纯静音或合成测试音可能返回空文本，这不等于接口故障。
  • 文件过长时，前端会分段上传并合并转写结果；若某段失败，界面会给出错误提示。
  • 名称含 realtime 的 ASR 仅支持 WebSocket，当前 HTTP 面板会标为「不可用」，请换非 realtime 模型。
