MCP（MCP 工具）

MCP 页面用于接入外部工具服务，让智能体可以调用企业已有系统、内部工具或第三方服务，完成查询、写入、分析等操作。

常见场景包括：查询内部业务系统、调用数据分析工具、对接办公自动化接口等。若你不确定是否需要 MCP，可先与系统提供方确认接入方式。

MCP 注册后，还需 部署 到 运行中 的 NineClaw 实例。也可在 NineClaw 创建实例 向导的步骤 3 中勾选 MCP。

访问地址示例：http://xxx:8510/mcps

进入页面​

  1. 打开 NineClaw WebUI。
  2. 在左侧导航中点击 MCP。
  3. 页面会展示已注册的 MCP Server。

页面上能看到什么​

区域说明
搜索框按名称、描述、命令或 URL 查找 MCP
+ 添加注册新的 MCP Server
部署把 MCP 工具部署到 NineClaw 实例
MCP 卡片展示 MCP 名称、传输方式和启用状态；点击进入详情页

点击 MCP 卡片进入详情页后，可在左侧查看配置与工具列表，在右侧直接试调工具（部署前验证连通性与参数）。

注册 MCP​

  1. 点击 + 添加。
  2. 填写名称和描述。
  3. 选择传输方式。
  4. 根据传输方式填写连接信息。
  5. 按需勾选 默认启用。
  6. 点击 保存。

URL 远程模式​

适合接入已经运行好的远程 MCP Server。

字段说明
URLMCP 服务地址
HTTP 头访问服务所需的鉴权信息或自定义请求头

STDIO 本地模式​

适合通过命令启动本地 MCP Server。

字段说明
启动命令启动 MCP 服务的命令
参数启动命令需要的参数
环境变量服务运行所需的密钥或配置

如果你不确定应该选择哪一种，优先和 MCP 服务提供方确认接入方式。

编辑 MCP​

  1. 在 MCP 卡片上点击 编辑。
  2. 修改名称、描述、连接参数或启用状态。
  3. 点击 保存。

进入 MCP 详情页​

  1. 在 MCP 列表页点击目标 MCP 卡片。
  2. 进入全屏详情页（左栏配置与工具，右栏工具调用）。
  3. 左上角 返回 可回到 MCP 列表。

访问地址示例：http://xxx:8510/mcps/<mcp-id>

区域说明
左上：配置信息名称、描述、传输方式、URL / 命令、启用状态；可编辑并保存
左下：工具列表搜索、获取 / 发现工具，并为每个工具开关启用状态
右侧：工具调用选择工具后填写参数并调用，查看响应与调用历史
中间分隔条拖动可调整左右栏宽度

发现与管理工具​

工具列表决定部署后智能体能调用哪些工具。建议只开启业务确实需要的工具，避免能力过宽。

  1. 进入 MCP 详情页。
  2. 在左侧 工具列表 区域点击 获取（或首次进入时的 发现工具），从 MCP Server 拉取工具清单。
  3. 用搜索框按名称或描述过滤工具。
  4. 对不希望开放的工具关闭右侧开关（已禁用的工具一般不会参与部署）。
  5. 拖动中间分隔条可加宽左侧，便于看清较长的工具名。

如果工具列表为空，优先检查：

检查项说明
URL 或命令地址、命令、参数是否正确
鉴权信息Token、Header、环境变量是否正确
网络NineClaw 服务器是否能访问该 MCP 服务
协议服务是否真正支持 MCP 工具发现

工具调用测试（部署前验证）​

MCP 没有类似 RAG / Web Search 的「全局检索」页面。部署前请在详情页右侧对单个工具做试调：确认服务可达、参数正确、返回内容符合预期。

  1. 在左侧工具列表中点击要测试的工具（高亮表示已选中）。
  2. 右侧 工具调用 区域会显示工具名称、描述和参数表单。
  3. 按表单填写必填 / 选填参数。
  4. 点击 调用。
  5. 在 响应 区查看返回内容（成功或错误）及耗时。
  6. 下方 调用历史 会保留本次记录；不需要时可 清空。

建议在部署前至少对核心工具各调用一次。联调失败时，先在本页修好连接与参数，再执行部署。

跨资源的全局检索请分别使用：RAG 全局检索、Web Search 全局检索。

部署到 NineClaw 实例​

部署前请确认目标实例处于 运行中。部署可能会让目标 Runtime 短暂重新加载。

  1. 在 MCP 列表页点击 部署。
  2. 选择要部署的 MCP。
  3. 选择要开放的工具。
  4. 选择一个或多个 运行中 的 NineClaw 实例。
  5. 点击 开始。
  6. 等待部署完成。

部署完成后，可以在目标实例中让智能体执行一个需要该 MCP 工具的任务，确认工具是否生效。

注意事项​

场景说明
MCP 未启用未启用的 MCP 不会参与部署
工具未发现部署时可能没有可选工具，需要先刷新工具列表
STDIO 模式需要确认目标环境能执行对应命令
URL 模式需要确认网络和鉴权信息正确

常见排查​

现象优先检查
工具列表为空MCP 服务是否在线，是否支持工具发现；是否已点「获取」
连接 / 发现失败URL、命令、鉴权信息、网络是否正确
详情页调用失败参数是否必填齐全；工具是否已启用；MCP 服务是否返回错误
部署后无法调用工具是否勾选，是否部署到正确实例
智能体调用报错MCP 服务本身是否返回错误
