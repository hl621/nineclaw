# Python 风格参考指南

## 命名规范

### 变量与函数
- 使用小写字母和下划线：`user_name`, `calculate_total()`
- 避免单字母名称（循环索引除外）
- 布尔变量使用肯定语气：`is_valid`, `has_permission`

### 类名
- 使用驼峰命名法：`UserManager`, `HttpRequest`
- 抽象基类后缀使用 `Base` 或 `Abstract`

### 常量
- 全大写和下划线：`MAX_SIZE`, `DEFAULT_TIMEOUT`

## 代码结构

### 导入顺序
1. 标准库导入
2. 第三方库导入  
3. 本地模块导入

每组之间空一行，每组内按字母顺序排序。

### 函数长度
- 单个函数不超过 50 行
- 圈复杂度不超过 10
- 参数数量不超过 5 个

### 注释规范
- 公共 API 必须包含文档字符串
- 复杂逻辑需要行内注释说明
- 注释使用完整句子，首字母大写

## 复杂度指标

| 等级 | 圈复杂度 | 说明 |
|------|----------|------|
| 🟢 低 | 1-5 | 易于测试和维护 |
| 🟡 中 | 6-10 | 可以接受，但需注意 |
| 🔴 高 | 11+ | 需要重构，难以测试 |

## 常见反模式

1. **深层嵌套**：超过 3 层缩进应考虑提取函数
2. **魔法数字**：使用命名常量替代字面量
3. **重复代码**：提取公共函数
4. **过长参数列表**：使用配置对象或建造者模式
