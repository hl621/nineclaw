# 问题分类法

使用本分类法对 Dogfood QA 测试期间发现的问题进行分类。

## 严重程度

### 严重（Critical）
问题导致核心功能完全无法使用，或造成数据丢失。

**示例：**
- 应用崩溃或显示空白页面
- 提交表单时用户数据在无任何提示的情况下丢失
- 身份验证完全失效（根本无法登录）
- 支付流程失败，在未完成订单的情况下却向用户收费
- 安全漏洞（例如 XSS、控制台中暴露凭据）

### 高（High）
问题严重影响功能，但可能存在规避方法。

**示例：**
- 点击关键按钮后毫无反应（但刷新后可恢复）
- 使用有效查询时搜索不返回任何结果
- 表单验证拒绝有效输入
- 页面可以加载，但关键内容缺失或乱码
- 导航链接指向 404 页面或错误页面
- 核心页面的控制台中出现未捕获的 JavaScript 异常

### 中（Medium）
问题较明显并影响用户体验，但不会阻碍核心功能。

**示例：**
- 页面某些区域的布局错位或重叠
- 图像加载失败（显示图像损坏图标）
- 性能缓慢（可见的加载延迟超过 3 秒）
- 表单字段缺乏恰当的验证反馈（输入错误时不显示错误消息）
- 控制台警告表明某些功能已弃用或配置错误
- 相似页面之间的样式不一致

### 低（Low）
不影响功能的轻微细节问题。

**示例：**
- 文本内容中存在拼写或语法错误
- 轻微的间距或对齐不一致
- 生产环境中遗留占位文本（"Lorem ipsum"）
- 缺少 Favicon
- 生产环境中出现了本不应保留的控制台 info/debug 消息
- 尚未构成 WCAG 不符合项的轻微色彩对比度问题

## 类别

### 功能（Functional）
功能未按预期工作的相关问题。

- 按钮/链接无响应
- 表单无法提交或提交结果错误
- 用户流程中断（无法完成多步骤流程）
- 显示的数据不正确
- 功能只能部分运行

### 视觉（Visual）
页面视觉呈现方面的问题。

- 布局问题（元素重叠、网格损坏）
- 图像损坏或媒体缺失
- 样式不一致
- 响应式设计失效
- Z-index 问题（元素被其他元素遮挡）
- 文本溢出或截断

### 无障碍（Accessibility）
妨碍或阻止残障用户访问的问题。

- 有实际含义的图像缺少 alt 文本
- 色彩对比度不足（未达到 WCAG AA）
- 无法通过键盘导航到达元素
- 缺少表单标签或 ARIA 属性
- 焦点指示器缺失或不清晰
- 内容与屏幕阅读器不兼容

### 控制台（Console）
通过 JavaScript 控制台输出检测到的问题。

- 未捕获的异常和未处理的 Promise rejection
- 网络请求失败（控制台中的 4xx、5xx 错误）
- 弃用警告
- CORS 错误
- 混合内容警告（HTTPS 页面中使用 HTTP 资源）
- 遗留了开发阶段的大量 console.log 输出

### 用户体验（UX）
功能可以正常运行，但体验不佳的问题。

- 导航或信息架构令人困惑
- 缺少加载指示器（用户不知道操作正在进行）
- 用户操作后没有反馈（例如点击按钮后没有可见结果）
- 交互模式不一致
- 破坏性操作缺少确认对话框
- 错误消息质量差，无法帮助用户解决问题

### 内容（Content）
页面上的文本、媒体或信息存在的问题。

- 拼写和语法错误
- 生产环境中出现占位/虚拟内容
- 信息过时
- 内容缺失（空白章节）
- 指向外部资源的链接损坏或失效
- 标签错误或具有误导性
