# Manim 视频技能

使用 [Manim 社区版](https://www.manim.community/) 制作数学和技术动画的生产流程。

## 功能

根据文本提示词创建 3Blue1Brown 风格的动画视频。智能体负责完整流程：创意策划、Python 代码生成、渲染、场景拼接和迭代优化。

## 使用场景

- **概念讲解** — “解释神经网络如何学习”
- **公式推导** — “用动画演示勾股定理的证明”
- **算法可视化** — “逐步展示快速排序的工作原理”
- **数据故事** — “用动画展示我们优化前后的性能指标”
- **架构图** — “展示我们的微服务架构逐步构建的过程”

## 前置条件

Python 3.10+、Manim CE（`pip install manim`）、LaTeX、ffmpeg。

```bash
bash skills/creative/manim-video/scripts/setup.sh
```
