# Excalidraw 调色板

在各类图表中一致地使用这些颜色。

## 主色（用于描边、箭头和强调）

| 名称 | 十六进制色值 | 用途 |
|------|-----|-----|
| 蓝色 | `#4a9eed` | 主要操作、链接、数据系列 1 |
| 琥珀色 | `#f59e0b` | 警告、高亮、数据系列 2 |
| 绿色 | `#22c55e` | 成功、正向、数据系列 3 |
| 红色 | `#ef4444` | 错误、负向、数据系列 4 |
| 紫色 | `#8b5cf6` | 强调、特殊项目、数据系列 5 |
| 粉色 | `#ec4899` | 装饰、数据系列 6 |
| 青色 | `#06b6d4` | 信息、次要内容、数据系列 7 |
| 黄绿色 | `#84cc16` | 额外内容、数据系列 8 |

## 柔和填充色（用于形状背景）

| 颜色 | 十六进制色值 | 适用场景 |
|-------|-----|----------|
| 浅蓝色 | `#a5d8ff` | 输入、来源、主要节点 |
| 浅绿色 | `#b2f2bb` | 成功、输出、已完成 |
| 浅橙色 | `#ffd8a8` | 警告、待处理、外部内容 |
| 浅紫色 | `#d0bfff` | 处理过程、中间件、特殊内容 |
| 浅红色 | `#ffc9c9` | 错误、关键事项、警报 |
| 浅黄色 | `#fff3bf` | 注释、决策、规划 |
| 浅青绿色 | `#c3fae8` | 存储、数据、内存 |
| 浅粉色 | `#eebefa` | 分析、指标 |

## 背景区域（分层图表中配合 opacity: 30-35 使用）

| 颜色 | 十六进制色值 | 适用场景 |
|-------|-----|----------|
| 蓝色区域 | `#dbe4ff` | UI / 前端层 |
| 紫色区域 | `#e5dbff` | 逻辑 / 智能体层 |
| 绿色区域 | `#d3f9d8` | 数据 / 工具层 |

## 文本对比度规则

- **在白色背景上**：文本颜色最浅应为 `#757575`。默认的 `#1e1e1e` 效果最佳。
- **浅色填充上的彩色文本**：使用深色变体（使用 `#15803d` 而非 `#22c55e`，使用 `#2563eb` 而非 `#4a9eed`）
- **白色文本**：仅用于深色背景（使用 `#9a5030` 而非 `#c4795b`）
- **切勿使用**：白色背景上的浅灰色（`#b0b0b0`、`#999`）——无法辨认
